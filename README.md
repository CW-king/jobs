# 채용공고판

공공기관의 **고졸·특성화고 대상 채용공고**와 **대기업·중견기업 생산·기술직 공고**를 하루 두 번 자동으로 모아 학생용 페이지로 보여 줍니다. 공고문에 나온 **자격증**도 자동으로 뽑아 정리합니다.

- 공공기관 수집: `scripts/collect.mjs` → `docs/data/jobs.json`
- 대기업·중견 생산직 수집: `scripts/collect-private.mjs` → `docs/data/private.json`
- 자격증 뽑기: `scripts/certs.mjs` (두 수집기가 같이 사용)
- Node 18 이상, 설치할 패키지 없음
- 학생용 페이지: `docs/index.html` (GitHub Pages로 게시)
- 자동 실행: `.github/workflows/update.yml` (매일 07:00, 18:00 한국시간)

## 2. 걸러내는 기준 (`scripts/classify.mjs`)

1. 학력조건 검색 "고졸"로 **접수 중**인 공고를 가져옵니다(잡알리오는 이때 학력무관 공고도 함께 줍니다).
2. 학력조건에 고졸·학력무관이 없는 공고(대졸 이상 전용)와 경력 전용 공고는 뺍니다.
3. **제목**에 `고졸`·`특성화고`·`마이스터고`가 있거나, **응시자격**에 `특성화고`, `마이스터고`, `직업계고`, `고졸 제한/전형/채용/수준`, `고등학교 졸업(예정)자에 한함`, `학교장 추천` 같은 말이 있으면 **특성화·고졸 전형**으로 표시하고 맨 위에 보여 줍니다.
4. 우대조건에 `고졸자`·`고졸인재`가 있으면 **고졸 우대** 태그를 붙입니다(가산점 항목이라 전형으로 치지 않음).
5. 나머지는 **고졸 지원 가능**으로 표시합니다.

## 2-1. 대기업·중견기업 생산·기술직 (`scripts/collect-private.mjs`)

- 출처: **고용24 채용정보 상세검색**(공개 페이지, 인증키 없음). 조건 `기업형태=대기업(01)·중견기업(20)`, `학력=고졸(03)`.
- 제목에 생산·제조·기능직·설비·정비·보전·전기·기계·용접·공조·품질·조립·가공·반도체·배터리·오퍼레이터 같은 말이 있는 공고만 남기고, 사무·영업·판매·미화·조리·배송 같은 공고는 뺍니다.
- 고용24 공식 Open API(채용정보)는 `coTp=01`(대기업), 학력 코드로 같은 조건을 걸 수 있지만, 신청 후 승인이 필요하고 기업회원 전용이라는 이용 후기가 있어 지금은 공개 검색 페이지를 씁니다. 승인을 받으면 API로 바꾸는 것이 안전합니다.
- 한계: 삼성·현대차·SK하이닉스처럼 **자기 채용 홈페이지에만 올리는 공채**, **학교 추천 채용**, 사람인·잡코리아에만 있는 공고는 빠질 수 있습니다.

## 2-2. 자격증 정리 (`scripts/certs.mjs`)

- 응시자격·우대조건·자격면허·모집요강 글에서 `○○기능사`, `○○산업기사`, `○○기사`, `○○기능장`, `컴퓨터활용능력`, `지게차`, `운전면허` 같은 이름을 자동으로 찾습니다. `전기(산업)기사`처럼 줄여 쓴 것도 나눠 셉니다.
- 페이지의 **자격증 정리** 탭에서 어떤 자격증이 공고에 많이 나오는지, 분야별(전기·전자 / 기계·용접 / 공조·에너지 / 안전·환경 / 운전·장비 / 정보·사무)로 보고, 누르면 그 자격증이 나온 공고를 모아 봅니다.
- 한계: 필수인지 가산점인지는 구분하지 않습니다. 공공기관은 자격증 가점표를 첨부파일(PDF·HWP)에만 넣는 경우가 많아 실제보다 적게 잡힙니다.

## 3. 처음 한 번만 하는 설정

1. **인증키 받기** (선택이지만 권장): data.go.kr 로그인 → "공공기관 채용정보 조회서비스" 검색 → [활용신청] → 마이페이지에서 **일반 인증키(Decoding)** 복사
2. **GitHub 저장소 만들기**: CW-king 계정에 새 저장소(예: `jobs`)를 만들고 이 폴더 내용을 올립니다.
3. **인증키 넣기**: 저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 `DATA_GO_KR_KEY`, 값에 인증키. (코드나 채팅에는 절대 붙여 넣지 않기)
4. **Pages 켜기**: Settings → Pages → Source: **GitHub Actions** 선택 (‘Deploy from a branch’가 아님! 자동 실행이 한 커밋은 그 방식의 빌드를 띄우지 않아 사이트가 갱신되지 않습니다)
   → 주소: `https://cw-king.github.io/jobs/`
5. **첫 실행**: Actions 탭 → "채용공고판 자동 수집" → Run workflow → 초록 체크가 뜨면 위 주소에서 확인
6. **구글 사이트에 링크 추가**: 학습자료실 허브에 "채용공고판" 버튼/카드로 위 주소를 연결

## 4. 그 뒤로는
